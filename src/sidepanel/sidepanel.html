    Obsidian connection

    Permissions

    Gleaner only needs to talk to Obsidian on this computer (127.0.0.1 / localhost).

    Saving images means downloading them from whatever site you are on, which browsers only allow with permission for all sites. Gleaner only fetches the image you right-click.

    Keyboard shortcuts

      Change them in Chrome/Edge at chrome://extensions/shortcuts (Edge: edge://extensions/shortcuts), or in Firefox via the gear menu on about:addons → Manage Extension Shortcuts.

      Setup help

      Option A: HTTP (simplest)
      1. In Obsidian: Settings → Local REST API → turn on Enable HTTP server.
      2. Set the API URL above to http://127.0.0.1:27123.
      3. Paste the API key, then Test connection.
      Option B: HTTPS with a trusted certificate
      1. Keep the URL as https://127.0.0.1:27124.
      2. Download the certificate: obsidian-local-rest-api.crt.
      3. Install it as a trusted root certificate authority in your OS (Windows: double-click → Install → Trusted Root Certification Authorities; macOS: Keychain Access → Always Trust), or in Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.
      4. Restart the browser, then Test connection.
